# Canvas Redesign – BSCCS Group 01

Our UX redesign of the Canvas Student app (University College Cork), as a static web page.

Open `index.html` to scroll through the slides, or click **Present** for full-screen mode (arrow keys to navigate, Esc to exit).

## Publish with GitHub Pages

1. Push this folder to a GitHub repo (keep `index.html` at the root).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`.
3. The site will be at `https://<username>.github.io/<repo-name>/`.
